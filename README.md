# Realt collector — сборщик аналитики по конкурентам (Этажи, Минск Мир)

Собирает **публичные** данные Realt.by по объявлениям агентства Этажи в ЖК
Минск Мир, накапливает историю и считает динамику. Работает **анонимно**:
логин и пароль не нужны и не используются.

## Файлы

| Файл | Назначение |
|---|---|
| `config.py` | Все настройки: агентства, фильтр Минск Мира, паузы, пути. Правится только здесь. |
| `queries.py` | Тексты GraphQL-запросов (как у самого сайта). Трогать не нужно. |
| `collector.py` | Главный сбор: проходит список → фильтрует Минск Мир → добирает просмотры → пишет снимок. |
| `analytics.py` | Считает динамику между снимками (прирост просмотров, цены, тарифы, появились/пропали). |
| `.github/workflows/collect.yml` | Запуск по расписанию на GitHub Actions (каждые 3 часа) + кнопка ручного запуска. |
| `requirements.txt` | Единственная зависимость — `requests`. |

## Что собирается

По каждому объявлению Минск Мира: агент (userUuid, имя, телефон, email),
цена и изменение цены, метраж, комнаты, этаж, дом, квартал (Каспиан, София,
Штадт, Медитерранеан, Парковая…), тариф продвижения, даты создания/обновления,
текущие просмотры. Для **новых** объявлений один раз восстанавливается история
просмотров по датам (задним числом).

## Результаты (папка `data/`)

- `data/raw/*.json` — сырые снимки (архив, из них можно пересчитать что угодно).
- `data/snapshots.csv` — главная таблица: строка на объявление на каждый момент
  снятия. Открывается в Excel.
- `data/listings_seen.json` — реестр всех виденных объявлений + их история просмотров.
- `data/reports/*.txt` — короткий текстовый отчёт за каждый прогон.
- `data/analytics/*.csv` — витрины: текущие объявления, сводка по агентам,
  по кварталам, изменения за период, появившиеся и пропавшие объявления.

## Запуск вручную (локально)

```bash
pip install -r requirements.txt
python collector.py     # собрать снимок
python analytics.py     # пересчитать витрины
```

## Запуск на GitHub (как и планировалось)

1. Залить эти файлы в репозиторий.
2. На вкладке **Actions** включить workflow (GitHub попросит подтвердить).
3. Он будет запускаться по расписанию из `collect.yml` и сам коммитить
   собранные данные обратно в репозиторий. Есть кнопка **Run workflow**
   для ручного запуска.

## Важно

- Сбор только читающий, с паузами между запросами — чтобы не создавать нагрузку.
- Аккаунт Елены нигде не используется. Это снижает риск до минимума.
- Динамика (поднятия, смена тарифа, снятия, изменения цены) копится **вперёд**,
  с момента первого запуска. История **просмотров** частично доступна задним
  числом и подтягивается для новых объявлений автоматически.
- Чтобы добавить агентство «Твоя столица» — раскомментируй строку в `config.py`.
