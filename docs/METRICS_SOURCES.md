# Смысл счётчиков Realt и источники данных

Проверено 27.10.2026 при сравнении Realt Radar с Kufar Radar.

| Показатель | Откуда взят | Что означает | Доступность |
|---|---|---|---|
| Просмотры объявления | публичный `objectsViewsCountsByUuids{views}` | открытия подробной страницы объявления по правилам Realt; не уникальные посетители и не показы в поиске | Да, на текущий момент |
| Прирост просмотров | разность счётчиков двух последовательных достоверных обходов одного UUID | число добавленных просмотров между двумя обходами, а не точное число от рекламы | Да, при полноценной паре замеров |
| Статус продвижения | `paymentStatus` в публичных объявлениях | тип продвижения на время снимка; начало и конец ограничены обходами | Да, с ограничениями |
| Открытие телефона | публичный сборщик не получает этого поля | число нажатий «показать телефон», не звонков | Пока не подтверждено в публичном API |
| Переходы из поиска | отсутствует отдельный публичный счётчик показов и переходов | клики из выдачи именно в карточку, а не все просмотры | Пока не подтверждено |
| Чаты/звонки | личная статистика объявления, если предоставляется владельцу | обращения; нельзя приравнивать к просмотрам | Не подтверждено для публичного радара |
| Стоимость продвижения | тарифы, предоставляемые пользователем | оценка расходов по истории включений пакетов; требует дат и правил пакета | Ожидает тарифы |

В описании приложения Realt за июнь 2025 упоминались просмотры, чаты и звонки в разделе «Мои объявления», то есть функции статистики для владельца. Наличие в личном кабинете не доказывает доступность данных публичного объявления или API без входа.

## Ограничения

Не подменять открытия телефона общими просмотрами. Не показывать точный день покупки рекламного пакета там, где известно только время наблюдения. Не считать расходы до получения тарифов. Не переносить цифры Kufar в Realt.

Следующая техническая проверка: определить разрешённый источник событий «Показать телефон», без использования чужой авторизации и без автоматического раскрытия личных номеров.
