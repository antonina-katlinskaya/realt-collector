# Эталон Kufar → Realt: наблюдения 27.10.2026

Источник: интерактивная страница radar.katlinskaya-antonina.workers.dev, прочитанная через подключённый браузер. Это описание не означает завершения визуальной проверки всех элементов.

## Навигация и фильтры
- Эталон имеет верхние разделы: Обзор, Продвижение, Объявления за период, Сотрудники, По часам, Что размещают, Топ органика, Топ продвижение.
- Выбраны пять приоритетных разделов: Продвижение, Объявления за период, Сотрудники, Топ органика, Топ продвижение.
- Фильтры Kufar: Сегодня, Вчера, 7/30/90 дней, Всё время, Свой период; дни недели; компания; несколько сотрудников с поиском; комнаты 1/2/3/4+; поиск текста; только новостройки; сброс.
- В Kufar фильтры находятся в сворачиваемом блоке.
- Эталон показывает время обновления в шапке.

## Подтверждённые механики
- На вкладке Продвижение Kufar показывает KPI: прирост просмотров за период, открытия номера, отношение открытий к просмотрам, активные объявления сейчас, новые за период, поднятия, включения продвижения.
- Приведены два графика по дням: просмотры и открытия номера.
- У Kufar есть специальное исключение искусственных открытий номера/просмотров, вызванных системными обходами.
- На карточках органики видны название, адрес, сотрудник, комнатность, площадь, цена, дата размещения, просмотры, открытия номера и коэффициент. Есть метка «быстрый старт».
- При открытии объявления Kufar показывает боковую панель с подробностями, графиками просмотров/открытий номера и событиями.

## Реальное соответствие Realt
- Сейчас Realt имеет интервальные просмотры и статусы продвижения, но **не имеет подтверждённого показателя открытий телефона**. Конверсию и исключение роботов как у Kufar нельзя имитировать.
- Realt показывает собственную измеренную динамику; нельзя переносить Kufar-числа или расценки.
- Названия вкладок и частичный внешний вид перенесены в отдельную ветку. Точное соответствие карточек ещё предстоит реализовать.
- Интерактивные действия браузера требуют отдельной функциональной проверки.

## Область сохранения
Ни сборщик Realt, ни сборщик Kufar, ни GraphQL-запросы, ни расписание не менять при фронтенд-переделке. Не объединять PR без проверки интерфейса и скорости.
