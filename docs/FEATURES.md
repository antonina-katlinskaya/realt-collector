# Единый дашборд Realt: функции двух исходных дашбордов

Источники требований: публичный Kufar Promo Report (интерфейс и `report/build_report.py`) и локальный `business_dashboard_v20.py` / `dashboard_v20.html` из пользовательского архива от 05.10.2026. Перенос относится к интерфейсу Realt; сборщик, запросы, фильтры, паузы, расписание и формат данных не меняются.

| Функция | Реализация в Realt |
|---|---|
| Сегодня, вчера, 24 часа, 7/14/30/90 дней, вся история, свои даты | Быстрые периоды и календарь; 24 часа — точный скользящий интервал |
| Несколько сотрудников, компании, комнатность, дома, поиск, дни недели | Фильтры; дополнительные площадь и точный адрес; сброс |
| Последний сбор, свежесть, охват | Число снимков, дата, отдельное предупреждение о недостатке истории |
| Сейчас в рекламе | Последний существующий снимок независимо от периода; основные агенты и раскрываемые остальные |
| Результат рекламы и рейтинг агентов | Прирост просмотров, количество объявлений и часов наблюдаемых интервалов; телефонная конверсия недоступна |
| Отдельные виды рекламы | Статусы Realt вместо пакетов Kufar, количество объявлений, прирост, часы и просмотры/час |
| Динамика по агентам | Цветные линии, включение/выключение через легенду |
| Все объявления, лидеры, сотрудники | Текущие, наблюдавшиеся в периоде, новые после исходного снимка, отсутствующие; ссылки и история; экспорт CSV |
| Действия сотрудников | Изменения цены/валюты, заголовка, параметров, статуса между соседними снимками; группировка полей одного объявления |
| История продвижения | Статусы, границы наблюдаемых последовательностей; дата покупки не предполагается |
| История объявления | Общий счётчик, интервальные приросты с разделением статусов, изменения, исходные исторические значения API |
| Что размещают | Площадь × комнатность, даты публикации из карточек, ссылки на объявления |
| Что работает | Рейтинг бесплатных на обоих концах интервалов, повторяющиеся слова заголовков, примеры объявлений |
| По часам, тепловая карта | Интервалы между снимками; тепловая карта дат публикации. Просмотры не распределяются по часам |
| Галерея обложек | По запросу загружается существующий сырой снимок, фотографии показываются с датой источника; рейтинг относится к объявлению, не фотографии |
| Пакеты, покупки, оплаченная/отработанная сумма, цена открытия | В текущем сборщике нет стоимости покупок и открытий телефона. Показывается отсутствие источника, а не нули |
| Поисковые маршруты, позиции, рекомендации по видимости | Текущий сборщик не делает такие замеры; доступность явно указана |
| Быстрый старт, эффект за 2 часа, до/после продвижения | Нужна подходящая частота и достаточные интервалы; трёхчасовые снимки не подтверждают двухчасовой эффект |
| Изменения обложки и всех фотографий | CSV не хранит фото. Галерея использует raw; автоматическое сравнение фотографий пока отсутствует |

## Правила данных

- Объявление определяется UUID, агент — userUuid; короткое имя не является уникальным ключом.
- Базовый снимок не означает, что все объявления только что опубликованы.
- Прирост считается только между соседними существующими снимками при наличии двух корректных неубывающих счётчиков. Пропуски и сбросы не превращаются в нули.
- Интервал полностью лежит внутри выбранного периода. Фильтр дня недели относится к его конечной дате; это не доказательство дня посещения.
- Одинаковый известный платный статус на концах — «при наблюдаемом продвижении»; два бесплатных — «бесплатно на обоих обходах»; смена/неизвестный статус — отдельная категория.
- Это наблюдаемая связь, не доказательство рекламного источника просмотров и не число уникальных клиентов.
- Отсутствие в следующем снимке не означает продажу; возможен неполный обход.
- Суммы и цены разных валют не складываются; сравнение цены объявления учитывает валюту.
- Существующий запрос исторических просмотров показывается как исходные значения, без неподтверждённой суточной интерпретации.

## Проверка

Расчёты проверяются на исходном CSV и синтетической истории: переходы статусов, сброс счётчика, исчезновение/возвращение, границы периода, фильтры и базовый снимок. Интерфейс проверяется на опубликованной странице. Дополнительный сбор не запускается.
