О данных продвижения

Статус рекламы виден на момент обхода. Даты — первое и последнее подтверждение, а не даты покупки пакета. ¹ Дни считаются по датам, когда реклама была замечена. Прирост просмотров доступен только для сопоставимых замеров; прочерк означает отсутствие данных. Открытия телефона и расходы пока не получены.

Топ органика

Новостройки без платного продвижения. Рейтинг прироста появится после двух достоверных обходов; до этого показываются общие просмотры с пометкой.

Когда росли просмотры

Выбери интервал, чтобы увидеть объявления и прирост. Снимок помечен временем начала сбора; фактическое получение счётчика могло быть позже. Точный момент посещения неизвестен.

Просмотры — счётчик открытий подробной страницы объявления, а не показы в поисковой выдаче, не уникальные покупатели, не нажатия на телефон и не звонки. Realt не сообщает источник каждого просмотра: «при продвижении» означает, что статус продвижения присутствовал на обоих соседних обходах. Между ними реклама могла измениться. Если статусы различаются, просмотры попадают в отдельную категорию.

Даты снимков — время начала сбора, а не точное время посещений. Прирост относится ко всему промежутку между двумя обходами; распределить его по часам или минутам нельзя. В период попадают только интервалы, полностью лежащие внутри выбранных дат.

Дата «наблюдается с» показывает начало непрерывной последовательности одинакового статуса в наших снимках. Если продвижение уже было при первом наблюдении, дата покупки неизвестна. Исчезновение означает отсутствие в следующем снимке, а не подтверждённую продажу.

Исторические значения просмотров и полнота данных

Для новых объявлений сборщик сохраняет значения отдельного запроса Realt по опорным датам. Его точная временная семантика не подтверждена этими файлами, поэтому эти значения доступны в карточке объявления как исходные данные и не превращаются в выдуманные ежедневные посещения.

Названия домов / кварталов определены сборщиком по заголовкам; пустое значение означает, что название не распознано. Полные имена известных сотрудников сопоставлены с их профилями; остальные агенты различаются по телефону и идентификатору.
